# Amrithesh K — Personal Portfolio

This is a self-contained multipage static website for GitHub Pages.

## Files

- `index.html` — home page
- `work.html` — realistic anonymised MEP commercial case studies
- `case-study.html` — detailed like-for-like quotation comparison case study
- `ai.html` — practical AI productivity perspective
- `deals.html` — interactive art of deal making page
- `contact.html` — contact and CV page
- `styles.css` — shared styling
- `script.js` — theme, navigation and interactive controls
- `profile-portrait.png` — locally bundled professional profile portrait

## GitHub Pages

Copy all files into the root of the repository used by `amritheshk22.github.io/amr/`. Keep the HTML files, `styles.css` and `script.js` in the same folder. The home page is `index.html`.

The site does not require a build step, framework or external dependency.
